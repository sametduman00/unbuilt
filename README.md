# Unbuilt — The home base for the vibecoding generation

**[unbuilt.me](https://unbuilt.me)** is a market intelligence platform for vibe coders, indie hackers, and no-code founders. Find what to build, validate if it's worth it, and get the exact tools to ship.

## What Unbuilt Does?

Unbuilt has three tools that cover the full journey from idea to execution:

### Launches (Free)
A daily feed of every new app launched on the App Store and Product Hunt. Scanned once per day. Every app gets an AI-generated breakdown:

- **What** — what the app does, in plain language
- **Difficulty** — how hard it is to build (simple, medium, hard) with reasoning
- **Competitors** — known alternatives already in the market
- **Build with** — exact tools to build it yourself (e.g. OpenAI, Supabase, Clerk, Paddle)
- **CTA** — "Dig my idea" to run a full market analysis, or "Get my Stack" for a build plan

No account required — completely free.

### Dig (Market Analysis)
Describe any app idea in plain language. Dig scans **70+ live data sources** — App Store, Google Play, Reddit, X/Twitter, YouTube, Product Hunt, LinkedIn — and returns a full market report in 5 minutes.

- Competitor list with ratings and weaknesses
- User pain points from real reviews and discussions
- Market gaps and untapped opportunities
- SWOT analysis and go-to-market suggestions
- **Opportunity score (0-100)** reflecting market saturation and demand

### Stack (Build Plan)
Tell Stack what you're building, your budget, and your technical level. It recommends the exact tools from **700+ options** with current 2026 pricing.

- Phased build plan: validate → launch → scale
- Filtered by budget tier: bootstrap, growing, funded, scale
- Filtered by skill level: no-code, low-code, developer
- Cost breakdown and setup instructions for each tool

## Ideas Directory

Unbuilt hosts **2,400+ pre-analyzed app idea pages** at [unbuilt.me/ideas](https://unbuilt.me/ideas), each with:

- Opportunity score (0-100)
- Estimated competitor count
- Market overview and key insight
- Related ideas for exploration
- Direct link to run a full Dig report

### Categories
SaaS, AI tools, developer tools, productivity, finance, health, education, e-commerce, marketing, content creation, freelancing, community, design, automation, analytics, HR & hiring, travel, real estate, food & restaurant, legal, pet, parenting, sustainability, and more.

### URL Patterns
- `unbuilt.me/ideas/best-[tool]-for-[audience]` — Best tools for specific audiences
- `unbuilt.me/ideas/[tool]-alternative` — Tool alternatives
- `unbuilt.me/ideas/how-to-build-a-[tool]` — Build guides with market context
- `unbuilt.me/ideas/top-[tool]-tools-2026` — Top tools ranked by market data
- `unbuilt.me/ideas/[tool]-market-gap` — Market gap analyses
- `unbuilt.me/ideas/[tool-a]-vs-[tool-b]` — Tool comparisons

## Who Uses Unbuilt

- **Vibe coders** building with Cursor, Lovable, Bolt, Replit, v0, or FlutterFlow who want to validate before they build
- **Indie hackers** looking for their next project or validating an existing idea
- **No-code founders** who need a tool stack recommendation
- **Founders** doing competitive research in their category
- **Anyone** who has built the wrong thing before and doesn't want to repeat it

## Why Unbuilt Exists

The vibecoding generation can build anything — that's the problem. Building fast in the wrong direction is still wrong. Most failed apps aren't bad ideas; they're ideas that already existed and nobody checked.

Unbuilt is the layer between "I have an idea" and "I'm building it." No more guessing. No more building blind.

## Tech Stack

- **Frontend:** Next.js 16, React 19, Tailwind CSS 4
- **Backend:** Supabase (PostgreSQL), Clerk (auth)
- **AI:** Claude API (Anthropic) for market analysis
- **Data:** 70+ live sources via APIs, 700+ tools database
- **Hosting:** Vercel
- **Analytics:** Google Analytics, Microsoft Clarity
